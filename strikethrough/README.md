# Strikethrough

Strikethrough adds GitHub-style `~~text~~` syntax to Kumbuka Markdown.

## Usage

```markdown
Deploy ~~Friday~~ Monday.
```

When the plugin is disabled, the source remains ordinary Markdown text and the tildes are preserved.

## Permissions

This plugin requests no Kumbuka capabilities. It selects Kumbuka's public `strikethrough` Markdown grammar.
