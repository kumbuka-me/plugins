# Footnotes

Footnotes adds Markdown footnote references and definitions to Kumbuka pages.

## Usage

```markdown
Kumbuka keeps useful context.[^1]

[^1]: A compact footnote.
```

Footnotes are disabled by default. Enable this plugin when the wiki should recognize footnote syntax.

## Permissions

This plugin requests no Kumbuka capabilities. It selects Kumbuka's public `footnote` Markdown grammar.
