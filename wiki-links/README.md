# Wiki Links

Wiki Links adds incoming and outgoing wiki-link relationships to Kumbuka page details.

The plugin owns the page-details widget and its presentation. Kumbuka core continues to parse `[[Page]]` references, maintain the page-link graph, resolve aliases, and mark broken links in page content independently of the plugin lifecycle.

## Permissions

- `pages:read` reads authorized backlinks and outgoing link metadata for the current page.
