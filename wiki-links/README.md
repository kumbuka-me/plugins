# Wiki Links

Wiki Links adds the incoming and outgoing wiki-link widget to Kumbuka page details.

The plugin controls only the page-details presentation. Kumbuka core continues to parse `[[Page]]` references, maintain the page-link graph, resolve aliases, and detect broken links independently of the plugin lifecycle.

## Settings

- **Page details widget** shows or hides backlinks and outgoing wiki links in page details.

## Permissions

This plugin requests no Kumbuka capabilities.
