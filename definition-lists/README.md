# Definition Lists

Definition Lists adds term/definition list syntax to Kumbuka Markdown.

## Usage

```markdown
Runbook
: A repeatable operational procedure.

Owner
: Platform team
```

Definition lists are disabled by default. Enable this plugin when the wiki should recognize this syntax.

## Permissions

This plugin requests no Kumbuka capabilities. It selects Kumbuka's public `definition-list` Markdown grammar.
