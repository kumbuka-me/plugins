# Automatic Links

Automatic Links turns plain URLs and email addresses into clickable links without requiring explicit Markdown link syntax.

## Usage

```markdown
Documentation: https://example.com/docs
Contact: team@example.com
```

When the plugin is disabled, the same text remains plain text unless it already uses normal Markdown link syntax.

## Permissions

This plugin requests no Kumbuka capabilities. It selects Kumbuka's public `linkify` Markdown grammar.
